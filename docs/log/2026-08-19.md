## Honest limitations

The streaming monitor is a semantic proof, not production-ready: it retains the
complete trace and is quadratic over a growing stream. It now has an explicit
clock, rejects backward events, and keeps observed failures terminal. The next
engineering milestone is bounded, incremental per-operator state.

## Remaining risks after incrementalization

- `atMostOnce` still needs an explicit window, scope end, or external state store
  before it can offer bounded retention.
- Progress deadline expiration currently scans every open obligation on each
  event or clock advance. This removes historical replay but can still be costly
  under high trigger volume; benchmark before adding a heap/index.
- Memory stats count logical retained entries, not byte size.

## Explicit uniqueness retention completed

## Progress deadline benchmark and index

- Measured the pre-change monitor with long-lived progress obligations in one
  partition. Five-sample medians were 7.44 ms for 1,000, 18.10 ms for 2,000, and
  76.27 ms for 4,000 opens. The last doubling cost 4.2× and confirmed quadratic
  behavior.
- Replaced arrays and full pending scans with a set per partition and a linked
  list ordered by deadline. Monotonic event time plus fixed `withinMs` keeps
  append order valid.
- Satisfaction unlinks its obligation directly. Expiration walks only the
  reached deadline prefix. Events with a different type from the consequent skip
  binding scans.
- Added `npm run bench:progress` and `docs/benchmarks.md` with environment,
  methodology, baseline, indexed results, and limits on interpretation.
- The first recorded reproducible indexed run measured medians of 1.24, 1.03,
  1.07, 2.49, and 4.60 ms for 1k, 2k, 4k, 8k, and 16k opens respectively.
- Later full-check reruns kept the same shape, with the 16k case between 4.56
  and 4.95 ms; the benchmark remains a local microbenchmark, not a universal
  throughput claim.
- Added a 10,000-obligation satisfaction test. All 1,250 generated differential
  traces still agree between online and finite engines.
